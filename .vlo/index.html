Build Web Apps Without the Framework Overhead

VLO is a lightweight Rust-powered web framework with real components, hierarchical layouts, server-side rendering, APIs, live reload, and a simple developer experience.

A MODERN RUST WEB FRAMEWORK

Simple enough to learn.
Powerful enough to ship.

VLO brings the pieces of modern web development together without forcing you through layers of configuration and complexity.

Rust Powered runtime
SSR Server-rendered pages
API Built-in REST routing
HMR Fast development reload
WHY VLO

Everything you need to build.

VLO focuses on the parts that make web development productive while keeping the underlying architecture straightforward.

⚡

Smart Live Reload

Change your VLO pages or components and see the result immediately during development.

🧩

Real Components

Build reusable components with props, children, nesting, layouts, and composable page structures.

🎨

Auto-Resolved Layouts

Create nested layouts that automatically resolve based on your page path, keeping your markup clean and DRY.

🔌

Built-in APIs

Define your API operations alongside your application and expose GET, POST, PUT, and DELETE endpoints.

🚀

Optimized Performance

Built-in HTTP caching, memory-cached APIs, and non-blocking I/O ensure your app is production-ready from day one.

📦

Single Binary

Develop and run VLO through one CLI instead of managing a large collection of separate development tools.
